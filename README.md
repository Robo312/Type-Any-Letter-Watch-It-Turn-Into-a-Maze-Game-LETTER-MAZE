# THE-MAZE-IS-WATCHING-YOUR-KEYBOARD

What if any letter could become a playable maze?

Introducing LETTER MAZE, an interactive maze game developed using Python and Pygame. Simply choose a letter, watch it transform into a maze, and challenge yourself to find the way out.

The game combines creative design, problem-solving, and programming to turn simple letters into an engaging gaming experience.

## Features

- Custom letter input for maze shape
- Three difficulty modes: Explorer, Adventurer, Master
- Randomized maze generation inside the letter mask
- Timer displayed during gameplay
- Monster chase mode in Master difficulty

## Requirements

- Python 3
- Pygame

## Run the Game

1. Install Pygame: `pip install pygame`
2. Run `Maze game.py`

## Controls

- Arrow keys to move
- Enter to confirm letter input

## Notes

- The exit is placed at the farthest reachable cell from the player.
- The Master mode adds a moving monster that chases the player.
